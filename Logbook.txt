Problem: DifferentStrings

First Idea:
Instead of performing literal insertions, we can view it as “sliding” the shorter string across the longer one to find the alignment that yields the fewest mismatched characters.

Why it might work:
Trying all valid offsets (from aligning the start to aligning the end) guarantees we’ll find the minimal difference. Sorting or backtracking isn’t needed, only pairwise comparisons for each possible alignment should be enough.
